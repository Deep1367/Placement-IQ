PLACEMENT IQ - SETUP & HOW TO RUN
===================================

REQUIREMENTS
------------
pandas
scikit-learn
joblib
streamlit
matplotlib
seaborn

(Save the list above as requirements.txt, or just install directly with
pip install pandas scikit-learn joblib streamlit matplotlib seaborn)


HOW TO RUN
----------

1. INSTALL PYTHON
   Make sure Python 3.9 or higher is installed.

2. (RECOMMENDED) CREATE A VIRTUAL ENVIRONMENT
   python -m venv venv

   Activate it:
     Windows:      venv\Scripts\activate
     Mac / Linux:  source venv/bin/activate

3. INSTALL REQUIREMENTS
   Save the requirements list above into a file named requirements.txt in
   your project folder, then run:
   pip install -r requirements.txt

4. PREPARE THE DATASET
   Create a folder named "data" in your project directory and place your
   dataset inside it as:
   data/placement_data.csv

   The CSV must contain these columns:
   cgpa, communication_score, aptitude_score, technical_score,
   projects_count, internship, backlogs, hackathons, certifications,
   placement_status

   (placement_status should be 0 = Not Placed, 1 = Placed)

5. TRAIN THE MODEL
   Run the training script first -- this creates the "models" folder with
   the trained model and a metrics file:
   python train_model.py

   You should see output like:
   Saved model to models/placement_model.pkl
   Accuracy: 0.xxxx

6. RUN THE APP
   Once training finishes, launch the Streamlit web app:
   streamlit run app.py

   This will open automatically in your browser at:
   http://localhost:8501


FOLDER STRUCTURE (after setup)
-------------------------------
project/
|-- app.py
|-- train_model.py
|-- requirements.txt
|-- data/
|   |-- placement_data.csv
|-- models/              (created automatically after training)
    |-- placement_model.pkl
    |-- metrics.json


NOTES
-----
- The app creates a local SQLite database file (placement_iq.db) in the
  project folder to store student records and prediction history.
- The VISUALS tab needs the model to have feature_importances_, which
  RandomForestClassifier provides automatically -- no extra setup needed.
- If you change the dataset's columns, update both train_model.py and the
  feature list in app.py (tab1's "features" DataFrame) to match.
